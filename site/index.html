Fill documents from a spreadsheet

Upload a Word template with {{Placeholders}} and a spreadsheet whose column headers match them. You'll get one document per row. New here? Read the user guide.

User guide

How to prepare your files and generate a batch of documents.

How it works

Docs Filler takes one Word template and one Excel spreadsheet. For every data row in the spreadsheet it produces a copy of the template with the placeholders swapped for that row's values, then hands you all the copies in a single .zip.

Step by step

  1. Build a Word template (.docx). Anywhere you want a value to appear, type a placeholder in double curly braces, e.g. {{First Name}}. Formatting (bold, font, size) is preserved.
  2. Build a spreadsheet (.xlsx). Put your field names in the first row — these are the column headers. Add one row per document below.
  3. Match the names. Each placeholder in the template must match a column header in the spreadsheet.
  4. Upload both files on the Create documents page and click Create documents.
  5. Download the .zip — it contains one filled document per data row.

Requirements — variable naming convention

A "variable" is a placeholder in the template that gets filled from the spreadsheet. Follow these rules so every variable resolves correctly:

  • Wrap in double curly braces: write {{Column Header}}. Single braces or other brackets are ignored.
  • Name = column header: the text inside the braces must be the same as a column header in the first row of the spreadsheet.
  • Case and spacing don't matter: {{First Name}}, {{first name}} and {{ First Name }} all match a First Name column. Matching is case-insensitive and collapses extra spaces.
  • Spaces inside names are fine: {{Start Date}} works — you don't need underscores or camelCase.
  • Unmatched placeholders are left untouched: if a {{Placeholder}} has no matching column, it stays in the document unchanged and is listed as a warning after processing. Check your spelling if you see one.
  • Empty cells become blank: a matching column with no value for a row simply inserts nothing.

Example

Template text:

Dear {{First Name}} {{Last Name}}, your start date is {{Start Date}}.

Spreadsheet:

First NameLast NameStart Date
JaneDoe01 Sep 2026
SamOkoro15 Sep 2026

Result: two documents — "Dear Jane Doe, your start date is 01 Sep 2026." and one for Sam.

Tip: use Advanced options on the Create documents page to name each output file after a specific column, or to pick a particular worksheet when your workbook has more than one tab.

Privacy

Everything happens locally in your web browser. Your template and spreadsheet are read and filled on your own device — they are never uploaded to a server, written to disk, or stored anywhere.
